## Debugging

No matter what the user says, always write a plan first, then walk through that plan. The plan should utilize the human to answer questions when it is impossible to proceed with a step. By default, each step should perform automated investigation. Review existing tools we have to do this. If the automated investigation cannot be done due to permissions, understanding, or missing tool, first update the debugging toolkit to fetch the missing data. If it cannot be be automatically run, ask the user to first grant the necessary permissions, otherwise ask them to run the tool.
